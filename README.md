# 🔐 Cybersecurity Suspicious Web Threat Interaction Analysis

## 📌 Project Overview

This project focuses on detecting and analyzing suspicious web threat interactions using Machine Learning and Data Analysis techniques. The dataset contains web traffic and attack-related information collected from CloudWatch logs.

The main objective of this project is to identify malicious or suspicious activities in web traffic and classify potential cyber threats using Machine Learning models.

This project demonstrates practical implementation of:

- Cybersecurity Data Analysis
- Threat Detection
- Machine Learning Classification
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Engineering
